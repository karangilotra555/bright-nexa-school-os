Automatic encrypted backups

Select a folder on this computer. Backups then run automatically after confirmed data changes and approximately every 30 minutes while the owner page is open, online and has folder permission.

Choose a folder to enable passwordless encrypted backups.

Recovery & verification

Backups use AES-256-GCM encryption. Export a recovery-key file once and store it separately from the folder; it is required if the browser or laptop is lost.

The browser cannot save to a local folder when it is closed. If permission expires, use “Allow folder access”. Backup verification does not restore a database; an independent restore procedure is still required.

Offline access (optional)

This is separate from automatic backup. Offline access stores a short-lived, encrypted, read-only copy of school records on this device. No student, fee or staff changes can be saved offline.

Encrypted offline access is off.

Offline unlock has its own security passphrase because it provides access to private student data without a live cloud login. Automatic folder backups do not require that passphrase.
