5 Practical Smart School Tools

Timetable, substitute teachers, student performance, Excel import and error detection — deterministic algorithms, no LLM calls.

100% API-FREE ENGINE
Private analysis workspace: Files are processed inside your browser, not uploaded to Bright Nexa or any AI provider. Nothing is automatically saved or synced to the school's database. Use a trusted device; review every result before official decisions. This is a pilot toolkit, not a replacement for school-approved records.

Smart Timetable Generator

Teacher assignments aur class-wise weekly requirements se clash-free timetable generate karo. Browser ke andar free scheduler chalega. Unfillable periods aur shortages separately dikhenge.

Smart Substitute Teacher

Generated timetable se free, subject-qualified teachers suggest honge. Existing assignment, leave aur same-period clashes ko avoid karega.

Substitute is a suggestion, not automatic allocation. Principal / timetable in-charge approval required.

Student Performance Analyzer

Marks CSV or XLSX import karne par subject-wise percentages, improvement aur below-threshold subjects niklenge. Ye student ki ability ka prediction ya diagnosis nahi karta.

student_id, student_name, subject, marks, max_marks; optional previous_marks, attendance_percent

Smart Excel / CSV Import

School ke old records ki CSV ya XLSX file choose karo. Common column names automatically map honge, data preview hoga aur errors check honge. Browser mein processing hogi; cloud database ko direct write nahi karenge.

School Error Detector

Imported datasets par rule-based checks: duplicate admissions/receipts, missing data, fee mismatches, marks out of range, attendance duplicates. Automatic deletion ya correction nahi hoti.
